# 최종 연구 방법

최종 실험의 식별자는 `sequential_best_future_f1_gain_hgb`이다. 이 문서는
이전 파일럿이나 앱의 그래프 라우터가 아니라 **매 단계 STOP/SEARCH 정책**을 설명한다.

## 문제와 동작

질문마다 필수 최초 검색을 수행하고 현재 답변을 생성한다. 총 검색 1·2·3회
이후의 상태에서 하나의 회귀 모델이 후속 검색의 답변 이득을 예측한다.
단계별 임곗값보다 크면 질의를 갱신하고 검색을 계속하며, 그렇지 않으면
현재 답변을 반환한다. 총 검색은 최대 4회다.

Qwen3-8B의 가중치는 고정한다. 학습하는 것은 scikit-learn의
`HistGradientBoostingRegressor`이며 MLP나 트랜스포머를 학습한 것이 아니다.
숫자 형태의 이득을 회귀한 뒤 임곗값으로 행동을 결정한다.

## 입력 105차원

| 범주 | 차원 | 예시 |
|---|---:|---|
| 질의 | 15 | 길이, 숫자 비율, 비교형 여부, 의문사 |
| 검색 이력 | 12 × 3 = 36 | 단계, 검색 점수, 신규 후보 비율, 질의 갱신의 충분성 보고 |
| 근거 집합 이력 | 11 × 3 = 33 | 제목 다양성, 질문·제목 중첩, 근거 추가·유지 비율 |
| 현재 답변·근거 연결 | 13 + 8 = 21 | 답변 유형·길이, 근거 지지, 연결 구조 |
| 합계 | 105 | 수치형 벡터이며 임베딩 차원이 아님 |

현재까지의 이력만 사용하고 미래 단계 영역은 0으로 채운다. 답변 관련
21개 특징은 현재 단계에서만 추출하며 이전 답변과의 일치 특징은 포함하지 않는다.
정답, 정답 근거 주석, gold hop, 데이터셋 식별자, 미래 F1은 입력에서 제외한다.

## 목표값과 학습

현재 이후 단계들의 최대 F1에서 현재 F1을 뺀 값을 목표로 삼는다.
모든 후속 답변이 나쁘면 음수를 그대로 유지한다. 바로 다음 검색만의
이득이나 성능 개선 확률을 학습하는 것은 아니다.

시드 42~46마다 세 데이터셋 train에서 각각 2,000문항을 다시 추출한다.
시드당 6,000질문 × 3상태 = 18,000개 상태-목표값 쌍이다.
각 시드 모델은 세 데이터셋을 합쳐 학습하고 데이터셋별로 평가한다.

| 설정 | 값 |
|---|---:|
| 손실 | squared_error |
| 학습률 | 0.05 |
| 최대 부스팅 반복 | 180 |
| 최대 리프 수 | 15 |
| 리프당 최소 표본 | 25 |
| L2 규제 | 3.0 |
| 최대 bin 수 | 255 |

자동 조기 종료와 내부 검증 비율 10%가 적용된다. 저장된 모델의 실제
반복 횟수는 시드 순서대로 73, 180, 76, 70, 180이다.

질문 단위 3분할 OOF 예측으로 단계별 임곗값을 보정한다. 같은 질문의
세 상태는 같은 분할에 속한다. 보정 목적은 F1에서 추가 검색당
0.001을 차감한 효용이며, 이는 100점 기준 0.1점이다. 이 가중치는
실측 시간이나 금전 비용의 환산값이 아니다. 실행 시 비용을 다시 더하지 않는다.

## 평가와 해석

HotpotQA 7,405 / MuSiQue-Ans 2,417 / 2WikiMultiHopQA 12,576문항의
전체 validation을 사용한다. 질문별 공식 후보 문서 안에서 생성한
1~4회 검색 궤적을 재생한다. 공개 웹 전체에서 검색한 결과나 온라인
종단 간 지연시간 실측으로 해석하면 안 된다.

고정 1~4회와 검색 깊이 분포 일치 무작위 종료를 비교한다. 무작위 종료는
한 번의 무작위 실행이 아니라 각 검색 깊이의 비율로 계산한 기대 F1이다.
이는 질문별 검색 배분 효과를 확인하지만 모든 간단한 종료 규칙에 대한
우위나 전체 계산 비용 감소를 입증하지 않는다.

각 데이터셋의 5개 시드 평균에서 검색은 줄고 F1은 높았지만, 고정 4회
대비 모든 시드의 신뢰구간이 양수인 것은 아니다. MuSiQue 시드 44의
점 추정 F1은 고정 4회보다 낮다. validation은 개발 중에도 사용했으므로
한 번도 보지 않은 독립 test 결과라고 주장하지 않는다.
